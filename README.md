# IPO Extension

## Overview

This simple Chrome extension utilizes the **Moneycontrol API** to fetch a company's IPO-related data, providing users with key information about upcoming and current IPOs.

## Key Company IPO Terms

| **Term**              | **Description**                                                                                                                                   |
|-----------------------|---------------------------------------------------------------------------------------------------------------------------------------------------|
| **Allotment Date**     | The date on which shares are allocated to investors.                                                                                             |
| **Close Date**         | The final date for bidding on shares in the IPO.                                                                                                 |
| **Company Name**       | The name of the company going public.                                                                                                            |
| **Date**               | The general IPO event date or key milestone.                                                                                                     |
| **Listing Date**       | The date on which the company's shares are listed and available for trading on the stock exchange.                                                |
| **Open Date**          | The first date when bids for the IPO are accepted.                                                                                               |
| **Refund Date**        | The date on which refunds are processed for unsuccessful IPO bids.                                                                               |

---

## Features

- Fetch real-time IPO data using **Moneycontrol API**.
- Display comprehensive information about a company's IPO, including allotment, listing, and refund dates.
- User-friendly interface for quick and easy access to IPO-related data.

---

## How to Use

1. Install the extension in your Chrome browser.
2. Open the extension to search for a company's IPO.
3. View all relevant IPO dates and details instantly.
